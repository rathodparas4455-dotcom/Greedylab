CHAPTER

Greedy Algorithms — Complete Notes

01 · What is Greedy?

A greedy algorithm builds a solution step by step by choosing the best available local option at every stage, without reconsidering previous choices.

while solution is not complete:
  choose best candidate
  if feasible → accept it

02 · Greedy Choice Property

A globally optimal solution can be reached by making a locally optimal choice first, then solving the remaining subproblem.

03 · Optimal Substructure

After a greedy choice, the remaining problem must contain an optimal solution to the original problem.

04 · When Greedy Works

Greedy is correct only when the problem has the required greedy-choice property and optimal substructure. It is not a universal replacement for DP.

05 · Advantages

  • Usually simple to design
  • Often fast and memory efficient
  • Natural step-by-step implementation
  • Excellent for many optimization problems

06 · Limitations

  • Local best may not be globally best
  • Correctness needs proof
  • Some problems need DP/backtracking
  • Choice cannot always be undone
